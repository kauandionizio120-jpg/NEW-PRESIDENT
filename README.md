# White House: World Crisis — Beta 0.7 APK Ready

Projeto Android preparado para gerar um APK automaticamente.

## O que esta Beta contém
- O jogo completo da Alpha 0.6 Dossiers dentro de um app Android.
- 60 acontecimentos principais e eventos ambientes.
- Dossiês antes das decisões.
- Globo estratégico.
- Política doméstica, Congresso, diplomacia, organizações internacionais,
  terrorismo e crime organizado tratados em nível estratégico.
- Reuniões secretas, tribunais, vazamentos, viagens e crises.
- Salvamento local no aparelho.
- Tela cheia em formato de aplicativo.

## Build automático no GitHub
O workflow `.github/workflows/build-apk.yml` compila `app-debug.apk`.
O APK debug é adequado para testes e já é assinado automaticamente pelas
ferramentas Android. Para publicação na Play Store será necessário criar
uma chave de release e gerar um AAB/release assinado.

## Importante
Os acontecimentos ficcionais do simulador não são notícias reais.
